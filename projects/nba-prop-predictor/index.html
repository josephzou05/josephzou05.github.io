NBA Prop Predictor — Model Results

By Joseph Zou · Updated Summer 2025

This project began as a personal frustration. Even after watching every Warriors game and tracking box scores, my NBA player prop picks often missed. Over time, that frustration turned into a question: could a data-driven model consistently outperform intuition?

What started as simple weighted averages has since evolved into a multi-model machine learning pipeline designed to predict single-game NBA point totals using recent performance, matchup context, and playing time trends.

Problem Setup & Data

The goal of this project is to predict an individual player’s points scored in a single NBA game. I collected historical player game logs and matchup data using the nba_api Python library, focusing on recent performance windows and opponent-specific context.

Key engineered features include rolling scoring averages, efficiency metrics, minutes trends, opponent-adjusted performance, and game context indicators such as home vs. away.

Model 1: Linear Regression Baseline

I began with a linear regression model to establish a transparent and interpretable baseline. This model serves as a sanity check and helps identify which features carry the strongest linear signal.

  • RMSE: 5.15
  • MAE: 3.93

The linear model performs reasonably well for mid-range scorers but tends to regress extreme performances toward the mean. Feature importance reveals that recent scoring efficiency and opponent-adjusted scoring are the strongest linear predictors.

Model 2: Tree-Based Regression Model

To capture non-linear relationships and feature interactions, I trained a tree-based regression model. This approach allows the model to adapt differently for high-usage scorers versus role players.

  • RMSE: 5.14
  • MAE: 3.92

The tree-based model provides a marginal improvement over the linear baseline and places greater emphasis on opponent-specific scoring history. This suggests that recent performance against similar defenses matters more than raw averages alone.

Model 3: Combined Minutes + Efficiency Model

To better reflect how scoring actually happens in games, I decomposed point prediction into two separate components: expected minutes played and points per minute efficiency.

I trained two independent models — one to predict minutes played and another to predict scoring efficiency — and then recombined them to produce a final point estimate.

  • Converted Points RMSE: 6.10
  • Efficiency RMSE (PPM): 0.251
  • Minutes RMSE: 6.41
This decomposition highlighted that minutes uncertainty — driven by coaching decisions, foul trouble, and injuries — remains the dominant source of error in NBA prop prediction.

Key Takeaways

  • Recent opponent-adjusted scoring is consistently the strongest predictor across models
  • Tree-based models capture useful non-linear structure but offer only marginal gains
  • Minutes volatility remains the largest source of prediction error
  • Even strong models must communicate uncertainty in a domain as stochastic as sports

Looking Forward

Future improvements include incorporating injury reports, back-to-back game effects, and real-time lineup data. While no model can eliminate randomness in sports, this project reinforced how machine learning can turn intuition into structured, testable decision-making.
